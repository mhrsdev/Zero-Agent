## نطاق الفحص

- جذر المشروع: `/opt/zero`
- فحص AST: عدد 194 ملف Python، منها 88 وحدة تحت `zero/` و24 script و82 ملف اختبار/دعم، بإجمالي 26,527 سطراً مفحوصاً.
- لم تظهر أخطاء parsing في الملفات المفحوصة.
- لا يوجد مجلد `.git` في الجذر؛ لذلك لا يمكن التحقق من التاريخ والفروع والفروقات والملكية عبر Git.
- قواعد البيانات، جلسات Telegram، السجلات، النسخ الاحتياطية، مساحات Office والـ secrets بيانات تشغيلية خاصة ولا يتم إعادة نشرها هنا.

## أسلوب الأدلة

الإحالات بصيغة `path:line`. الكلمات «حالي»، «غير مؤكد»، «مشتبه» و«غير مثبت» تميز بين الملاحظة المباشرة والافتراض المعماري.
